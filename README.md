# online-quiz-website
THIS IS BASICALLY AN ONLINE PLATFORM AND A MINI PROJECT FOR ONLINE QUIZES, USING HTML, CSS AND JS.
Interactive Online Quiz Application for Computer Studies

Project Overview

The Interactive Online Quiz Application for Computer Studies is a web-based educational application developed to help students test their knowledge of Computer Studies.

The application provides an interactive platform where students can answer computer-related questions within a specified time limit and assess their understanding of the subject.

The system begins with a welcome page that displays information about the quiz, including the number of questions, time allowed, and subject. Students can start the quiz by clicking the Start Quiz button.

Project Objectives

The objectives of this project are:

- To develop an interactive online quiz application for Computer Studies.
- To provide students with an opportunity to test their computer knowledge.
- To encourage independent learning and self-assessment.
- To improve students' understanding of Computer Studies.
- To provide a simple and user-friendly quiz interface.

Features

The application includes the following features:

- Welcome page for students.
- Start Quiz button.
- Five Computer Studies questions.
- Time limit of 30 seconds per question.
- Interactive question display.
- Computer Studies quiz information.
- Automatic score calculation.
- Quiz result display after completion.

Note: Features such as automatic score calculation and result display depend on the functionality implemented in the JavaScript file.

How to Run the Project

Follow these steps to run the application:

1. Install Visual Studio Code on your computer.
2. Open Visual Studio Code.
3. Select File → Open Folder.
4. Open the project folder.
5. Ensure that the HTML, CSS, and JavaScript files are in the same folder.
6. Open "index.html".
7. Run the application using Live Server or a web browser.
8. Click the Start Quiz button to begin.

How the Application Works

1. The student opens the application.
2. The welcome page displays the quiz information.
3. The student clicks the Start Quiz button.
4. The application displays the quiz questions.
5. The student selects answers within the allocated time.
6. The system evaluates the student's answers.
7. The final score is displayed after the quiz is completed.
